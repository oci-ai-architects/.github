# Code of conduct

This community follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). The short version: be respectful, argue about the work and not the person, and assume good faith.

## Reporting

If someone's behaviour is a problem, report it privately by opening a security advisory on any repository in this organization and marking it as a conduct report, or by messaging the maintainer [@frankxai](https://github.com/frankxai) on GitHub. Reports are read by the maintainer only.

## Enforcement

The maintainer may edit or remove comments, close issues and pull requests, and block accounts that break this code. Decisions are explained to the person affected unless doing so would put someone at risk.
